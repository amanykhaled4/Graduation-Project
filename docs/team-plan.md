# خطة الفريق

**الهدف:** الويب والأبلكيشن والـ Backend يخلصوا في الترم الأول (أسبوع 13).
**المطلوب من كل واحد:** حوالي ساعتين لـ 3 ساعات في اليوم.

## توزيع الأدوار

| الشخص | الدور | هيتعلم إيه |
|---|---|---|
| أماني (الليدر) | Backend + إدارة الفريق + ربط الأجزاء | C#، و ASP.NET Core، و SQL |
| عضو 1 | Mobile App | Dart و Flutter |
| عضو 2 | Web Dashboard | HTML و CSS و JavaScript و Bootstrap |
| عضو 3 | تصميم الشاشات + التوثيق + الاختبار | Figma، و draw.io، و Postman |

## الكورسات

| الدور | الكورس |
|---|---|
| Mobile | Dart ثم Flutter للمبتدئين بالعربي (مثلًا Tharwat Samy أو وائل أبو حمزة). ابعتوا القايمة لأماني قبل ما تبدأوا |

## قواعد الفريق
1. **كل واحد يعمل حساب GitHub**، وأماني تضيفه للريبو.
2. **كل واحد يشتغل في فولدره:** `mobile/`، و `frontend/`، و `docs/`، و `backend/`.
3. **كل يوم:** رسالة قصيرة في الجروب: "خلّصت إيه، وهعمل إيه بكره، وواقف عند إيه".
4. **اجتماع أسبوعي** 30 دقيقة نراجع فيه اللي اتعمل.
5. **أي حاجة وقفت معاك أكتر من ساعة**، اسأل على طول.
